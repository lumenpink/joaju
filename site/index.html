🚀 Inicialização Rápida no Ambiente Local

O Joaju provê interfaces prontas para o fluxo de trabalho integrado com o cccp:

Terminal (Bash) 
# 1. Iniciar servidor com recarga contínua (hot watcher):
cccp serve --dev
# ou: npm run dev

# 2. Executar demonstração com dados semeados (Exposição VDNKh):
cccp serve --demo
# ou: npm run demo

# 3. Executar suíte completa de testes unitários e de cobertura:
npm test
npm run test:coverage

📊 Sintaxe de Diagramas e Gráficos

Escreva fluxogramas, grafos, sequências e arquiteturas diretamente em blocos de código declarativos com controle fino de escala:

Markdown (Diagrama Mermaid) 
```mermaid
%% width=85% max-width=600pt
graph TD
    A[Coleta de Dados / Amostragem] --> B[Processamento & Limpeza]
    B --> C{Validação dos Dados}
    C -->|Válido| D[Análise Estatística & Modelagem]
    C -->|Inconsistente| E[Filtragem de Ruído / Descarte]
    D --> F[Visualização & Relatório Final]
```

🧬 Módulo Especializado: Heredogramas Clínicos

Escreva dados genealógicos tabulares simples diretamente em blocos de código com diretivas visuais:

Markdown (Heredograma Clínico) 
```heredograma
%% layout.width=90% layout.max_width=550pt cex=0.85
id,pai,mae,sex,fenotipo,label
1,0,0,M,wt,I.1 (Avô)
2,0,0,F,wt,I.2 (Avó)
3,1,2,M,het,II.1 (Pai Portador)
4,0,0,F,wt,II.2 (Mãe Não-Afetada)
5,3,4,F,hom,III.1 (Probanda Afetada)
6,3,4,M,wt,III.2 (Irmão Hígido)
```

📡 Referência da API Local

GET /health

Sonda de integridade operacional retornando status: "ok", versão atual e tempo de atividade.

POST /render

Renderização rápida de fragmentos declarativos (diagramas Mermaid ou heredogramas) devolvendo SVG vetorial para visualização interativa instantânea.

POST /compile

Pipeline completo de compilação: pré-processa diagramas, executa filtros Pandoc e compila o documento ABNT final em PDF vetorial de alta resolução.
