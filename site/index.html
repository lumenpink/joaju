Orquestrador Declarativo de Diagramas & Gráficos Científicos

Transforme Markdown declarativo em PDFs acadêmicos e gráficos vetoriais estritamente formatados conforme a ABNT NBR 14724, com suporte a diagramas multi-engine (Kroki, Mermaid) e extensão para heredogramas clínicos.

Explorar Motores & Configurações Guia Rápido
📊

Diagramas Declarativos (Kroki)

Suporte transparente a blocos Mermaid, PlantUML, Graphviz e Vega-Lite através da integração isolada com o gateway Kroki.

⚡

Tipografia Vetorial com Typst

Diagramação de alta velocidade com três perfis bibliográficos CSL integrados: trabalho-ufsc (capa institucional padronizada), abnt (NBR 14724) e vancouver (biomédico).

🛡️

Hermeticidade e Padrão GOST

Ambiente conteinerizado multi-stage OCI rodando com usuário não privilegiado e suíte de testes com cobertura superior a 90%.

🧬

Extensão: Heredogramas Clínicos

Módulo especializado para geração de heredogramas no padrão NSGC via motor R (pedtools e kinship2) para publicações biomédicas e genéticas.

🧩 Motores e Módulos Disponíveis

Selecione um motor para ver a documentação exaustiva de parâmetros, opções repassadas aos motores nativos e múltiplos exemplos práticos prontos para uso:

🧬

pedtools Principal

Heredogramas clínicos modernos (pedsuite R) com auto-dimensionamento vertical proporcional às gerações, half-fill e legendas.
🕰️

kinship2 Legado

Motor legado de heredogramas clínicos baseado em kinship2 para compatibilidade retroativa com notas existentes.
📋

table

Tabelas com tipografia acadêmica estrita (padrão APA/ABNT com 3 réguas horizontais, alinhamento numérico e notas de rodapé).
⚗️

openchemlib & openbabel

Renderização vetorial SVG de estruturas químicas 2D a partir de notação SMILES e arquivos MOL/SDF.
📊

mermaid

Fluxogramas, sequências, classes, estados, gitgraph e gráficos de Gantt renderizados via Kroki em alta resolução.
📐

d2

Linguagem moderna de diagramação declarativa para arquitetura de sistemas, topologias de rede e fluxos de dados.
☕

plantuml

Diagramas UML clássicos e de engenharia de software (casos de uso, componentes, sequência e pacotes).
🕸️

graphviz

Grafos direcionados e não-direcionados, autômatos finitos e redes de relacionamentos em linguagem DOT.
📜

gist

Inclusão resiliente de scripts analíticos (R, Python, Julia, SQL) hospedados no repositório externo (Gist) com cache em memória.

🚀 Inicialização Rápida no Ambiente Local

O Joaju provê interfaces prontas para o fluxo de trabalho integrado com o cccp:

Terminal (Bash) 
# 1. Iniciar servidor com recarga contínua (hot watcher):
cccp serve --dev
# ou: npm run dev

# 2. Executar demonstração com dados semeados (Exposição VDNKh):
cccp serve --demo
# ou: npm run demo

# 3. Executar suíte completa de testes unitários e de cobertura:
npm test
npm run test:coverage

📚 Perfis Tipográficos Suportados (YAML Frontmatter)

Configure o comportamento visual e o padrão bibliográfico no cabeçalho da sua nota no Obsidian:

Markdown (Cabeçalho YAML) 
---
titulo: Elaboração de Heredograma Familiar e Análise Genético-Clínica
subtitulo: Estudo de Caso Ambulatorial e Herança Autossômica Recessiva
autor: Equipe de Genética Médica
instituicao: Universidade Federal de Santa Catarina
local: Florianópolis
ano: 2026
perfil: trabalho-ufsc # Opções: 'trabalho-ufsc', 'abnt' ou 'vancouver'
---
Perfil (perfil:) Finalidade e Regras Tipográficas Estilo de Citação / CSL Variáveis Suportadas no YAML
trabalho-ufsc Trabalhos acadêmicos e monografias da UFSC. Gera capa institucional padronizada, folha de rosto, margens oficiais (3cm/2cm) e paginação no canto superior direito a partir da folha 2. trabalho-ufsc.csl (ABNT/UFSC) titulo, subtitulo, autor, instituicao, local, ano, fonte, tamanho
abnt Artigos científicos gerais e relatórios técnicos. Segue rigorosamente a ABNT NBR 14724 com espaçamento 1.5, numeração progressiva de seções (NBR 6024) e referências alfabéticas autor-data. abnt.csl (NBR 6023) titulo, subtitulo, autor, fonte, tamanho
vancouver Artigos e comunicações nas áreas médica, biológica e da saúde. Citações numéricas sequenciais entre parênteses no texto e referências ordenadas por ordem de aparição conforme padrão ICMJE/NLM. vancouver.csl (ICMJE) titulo, subtitulo, autor, fonte, tamanho

📊 Sintaxe de Diagramas e Gráficos

Escreva fluxogramas, grafos, sequências e arquiteturas diretamente em blocos de código declarativos com controle fino de escala:

Markdown (Diagrama Mermaid) 
```mermaid
%% width=85% max-width=600pt
graph TD
    A[Coleta de Dados / Amostragem] --> B[Processamento & Limpeza]
    B --> C{Validação dos Dados}
    C -->|Válido| D[Análise Estatística & Modelagem]
    C -->|Inconsistente| E[Filtragem de Ruído / Descarte]
    D --> F[Visualização & Relatório Final]
```

🧬 Módulo Especializado: Heredogramas Clínicos

Escreva dados genealógicos tabulares simples diretamente em blocos de código com diretivas visuais:

Markdown (Heredograma Clínico) 
```heredograma
%% layout.width=90% layout.max_width=550pt cex=0.85
id,pai,mae,sex,fenotipo,label
1,0,0,M,wt,I.1 (Avô)
2,0,0,F,wt,I.2 (Avó)
3,1,2,M,het,II.1 (Pai Portador)
4,0,0,F,wt,II.2 (Mãe Não-Afetada)
5,3,4,F,hom,III.1 (Probanda Afetada)
6,3,4,M,wt,III.2 (Irmão Hígido)
```

📡 Referência da API Local

GET /health

Sonda de integridade operacional retornando status: "ok", versão atual e tempo de atividade.

POST /render

Renderização rápida de fragmentos declarativos (diagramas Mermaid ou heredogramas) devolvendo SVG vetorial para visualização interativa instantânea.

POST /compile

Pipeline completo de compilação: pré-processa diagramas, executa filtros Pandoc e compila o documento ABNT final em PDF vetorial de alta resolução.
