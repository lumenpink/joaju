🧬 Guia de Campos — Heredograma (Pedigree)

O gerador aceita tabelas no formato CSV dentro de blocos ```heredograma. Abaixo estão todos os campos e mapeamentos suportados pelo motor genético:

1. Colunas Estruturais (Genealogia)

Coluna Sinônimos Obrigatório? Descrição e Valores Aceitos
id — Sim Identificador único do indivíduo (ex: 1, 2, filho1).
pai dadid Sim ID do pai. Use 0 ou deixe vazio se for fundador / desconhecido.
mae momid Sim ID da mãe. Use 0 ou deixe vazio se for fundadora / desconhecida.
sex — Sim M ou 1: Masculino (Quadrado)
F ou 2: Feminino (Círculo)
?, U ou 3: Sexo Indeterminado (Losango)
T ou 4: Gestação Interrompida / Aborto

2. Campo de Fenótipo / Afecção

Coluna Sinônimos Valor Informado Resultado Gráfico (Padrão Internacional)
fenotipo afetado, affected wt, 0, higido, selvagem Normal / Não Afetado: Símbolo vazio (branco).
het, heterozigoto, portador, carrier Portador Heterozigoto: Metade esquerda preenchida verticalmente.
hom, 1, afetado, doente, mut Afetado / Homozigoto: Preenchimento sólido completo.
?, na, desconhecido Fenótipo Desconhecido: Ponto de interrogação (?) no símbolo.

3. Campos Clínicos Extras (Opcionais)

Coluna Sinônimos Valores Efeito Gráfico
label — Texto livre Texto exibido logo abaixo do símbolo (ex: "Pai", "Probanda", "III-2"). Se omitido, exibe o id.
falecido status 1 (falecido) ou 0 (vivo) Traço diagonal cortando o símbolo, indicando óbito.
gemeo_com — ID do irmão Liga os indivíduos como irmãos gêmeos a partir do mesmo nó.
tipo_gemeo — MZ ou DZ MZ (monozigóticos / idênticos com barra) ou DZ (dizigóticos / fraternos).

4. Diretivas Visuais (Linha %%)

Você pode ajustar proporções colocando uma linha iniciada por %% antes do CSV:

%% symbolsize=2.2 cex=0.85 branch=0.4 layout.width=90%
  • symbolsize: Escala dos símbolos (padrão: 2.2).
  • cex: Escala da fonte dos textos e rótulos (padrão: 0.85).
  • branch: Proporção e comprimento dos ramos de junção (padrão: 0.4).
  • plot_width / plot_height: Dimensões manuais do SVG em polegadas (ex: plot_height=3.5).
